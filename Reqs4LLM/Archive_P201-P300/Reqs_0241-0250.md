## 落點與理由

1. **零 npm 相依**：TypeScript **7.0.2** 已移除 `target: es5`／`module: none`（`TS5108`／`TS6046`）。否決「裝舊版 TS」；改以 ES5 寫法 ＋ **ES2015** 編譯 ＋ `target: es2015` ＋ 產物守衛（`tools/es5guard.mjs` 比對 13 條語法 ＋ 13 條 API ＋ 4 條模組殘留），`esbuild` 與 `node_modules/` 俱不需。
2. **標籤與排列不手抄**：`--extra-label-prefix` 導出 `extraLabels`；`tools/settings-surface.mjs` 解析 `Shared.swift` 之 `KeyboardParser` 宣告序＋`localizedMenuName`＋`UserDefRenderableImpl.swift` 之 `[7,100]` 分隔線 ⇒ `VCA_SURFACE`；介面實序 **0,1,4,5,8,6,7,3,2,9,10**（助手省略首項前之線，生效者僅 `[7]`）。
3. **題庫 ⊆ 設定介面曝露面**（新通則）。事主原文：「只要不是 SettingsUI / SettingsCocoa 曝露給使用者的選項，就不要在 Web Config Assistant 裡面出現。」⇒ 掃 31 檔生成 `107` 鍵之曝露面（移除五鍵）。題庫 **105 鍵／107 題 → `100` 鍵／`102` 題**，fixture 降為 **95／92／92／1** 項。

**動線**：兩樞紐收攏至背景頁，逐項頁降為選項——**快速**（預設）四頁＝歡迎→背景→起始配置→摘要；**逐項**十三頁。起始配置頁示〈來源〉、列鍵值供核對、以 `.vca-note-box` 示提前結束之提醒；「只套用起始配置」決定 `buildSteps(…,expressOnly)` 是否收錄逐項頁；「跳到摘要 ＞」僅在距摘要兩頁以上時露面，「上一步」依 `state.skipFromIndex` 原路折返；`?express=0` 可還原（`updateUrlState()` 帶 `express`）。

**起始配置之內容**：即 `questions.ts` 之推薦值表（`recommendationFor`）對該 profile 之全集，**不立第二份策展表**。`starterFor()` 只收 `effectiveRecommended` 非 `null` 者，經 `coerceValue`／`validateValue`／`validateValue()` 過濾；`syncStarter()` 不覆蓋 `state.manual`，取消只撤 `state.starterAdded`；配置名預設「〈來源〉的起始配置」（`summary.starterTitle`）。空組合法：macOS 內建注音組句派示「沒有需要先套用的項目」（`starter.empty`）。

## 要解決的問題

- 外部相依原為 node ＋ npm。事主原文（2026-09-25）：「新任務：免除對 node 的依賴、且現階段不考慮 windows / linux 下的編譯。這個作為 Phase 246 任務請落實。」
- 助手是全生態圈唯一需要 `tsc` 之產線，其產物原不進 main bundle；而 npm 版之 `tsc` 只是 `#!/usr/bin/env node` 啟動器（`lib/tsc.js` 僅 609 B，靠 `getExePath.js` 定位 `@typescript/typescript-<平台>/lib/tsc`），一用即等於仍依賴 node。
